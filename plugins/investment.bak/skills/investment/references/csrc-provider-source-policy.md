# 证监会供应方声明净值版本协议

本协议只支持 `csrc_official_provider_declared_nav_v1`，不是一般 HTTP 回退。其来源身份由实际取得并核验的中国证监会 HTTPS 原监管文件确认；文件第119页明确指定 `http://eid.csrc.gov.cn/fund` 为基金电子披露网站，并说明历史信息报送及展示制度。依据为[监管实施规定原文](https://www.csrc.gov.cn/csrc/c101950/c1047975/1047975/files/%E9%99%84%E4%BB%B61_%E4%B8%AD%E5%9B%BD%E8%AF%81%E7%9B%91%E4%BC%9A%E5%86%B3%E5%AE%9A%E4%BF%AE%E6%94%B9%E7%9A%84%E8%A7%84%E8%8C%83%E6%80%A7%E6%96%87%E4%BB%B6.pdf)、[信息披露办法](https://www.csrc.gov.cn/csrc/c106256/c1653985/content.shtml)及[净值 XBRL 报送与展示说明](https://www.csrc.gov.cn/csrc/c100028/c1002527/content.shtml)。制度支持明确提供者、申报主体、托管复核及日期版本声明；制度不是每条 HTTP 元数据的签名证明。

唯一 HTTP 入口为官方原导航中的 `eid.csrc.gov.cn/fund/disclose/daily_report_list_page.do`。原查询、全部分页、响应字节、实际取得时刻、网络错误和本次覆盖原分母必须保存。全局 `source_fetch` 仍仅允许严格 HTTPS；其他 HTTP 主机、路径、重定向或包装代理不能借本协议入库。

每个数值行必须在同一原对象中关联份额代码、主体与分类、价格行/申报实体、净值日期、单位与累计净值、上传时刻以及供应方公告日期。不用净值日加固定延迟，不把网页模板更新时间当原公告时间。提供者声称的公告日只有日精度：历史使用取该日之后的保守日界；当天真实取得且价格经核对的版本可使用实际取得这个更早的已知证据。实际系统 capture 始终保持真实今天，不能改成供应方过去日期。

所有消费价格逐份额、逐日期、逐单位与累计值从天天基金/发行人独立 HTTPS 原字节再提取；原法定 CNY 场外份额身份仍须核验。价格核对不认证 HTTP 公告日，也不证明数据库永远不修改。协议依赖的明确机构假设为：供应方将原价格、上传实体和公告日关联到本条当前价格版本。上传晚于声称公告日、日期倒置、同版冲突、价格或身份不一致均拒绝，不用 `max` 猜一个时间挽救该行。全部此前原页重验，未知已被替换的旧价格保持未知，迟到修订前的原点不使用新版本。

跨原页同申报实体发生矛盾时，该实体的全部份额都排除，不能保留最先遇到的匹配价格；未请求兄弟份额的矛盾同样参加检查。原主体货币声明若非空，必须明确支持 CNY，美元、混合或无法识别的声明不能靠价格匹配放行。原声明为空时保持未知；当前法定份额 CNY 身份不能补证过去的改币、份额转换或历史身份连续性。

必须区分 `publisher_identity_verified=true`、经实际核对的价格事实、`transport_authenticated=false` 和 `publication_metadata_independently_authenticated=false`。不能宣称原历史发布时间得到独立密码学认证；模型结果条件于受审供应方版本协议及数据正确性，统计置信度不覆盖传输伪改或机构记录错误。

本价格协议不能顺便赋予分红/拆分权益历史资格。目前只允许原 HTTPS 完整历史普查明确没有分红与拆分、且原 NAV 现金项为零的份额建立零现金版本。非零或覆盖不明权益须有自己的 record/ex/pay、归属和可得版本；价格匹配不会令其成熟。原 H、完整中间路径、费用、持有期、现金、训练/选择/独立校准与当前交易资格门槛均保留。

协议准入只产生可由独立验证器消费的来源版本，不自动授予最优基金、真实投资者收益、风险通过或调整资格。真实最新版安装、正常首次与再次调用仍按 README 隔离规则验收，单源原文检查和脚本不能代替主链。
