# 可复算财务分析

## 工具与范围

统一入口实际调用当前算法、账本、校验与报告服务。不存在仅凭ChatGPT订阅就自动取得的专用理财权限、交易接口或商业数据资格。理论、执行成功、收益优势及来源真实性分别说明。

| 分析 | 应用与证据 |
|---|---|
| 财务建模 | 账户、现金流、份额、费用和结算：保存输入、公式和版本 |
| 情景分析 | 共同历史情景、风险预算、资金档位：说明假设和敏感性 |
| 方案比较 | 维持、调整、新品类、追加：同口径成本与约束 |
| 效果验证 | 开发回放、固定终点前瞻：保留全部操作、基准和缺口 |

公司现金流DCF不默认用于指数或黄金价格预测。计算能力不证明预测可靠。

## 精度与资金

实际账户财务值使用Decimal字符串；未知值不能用0替代。可用现金等于已确认现金扣除当前冻结；应收、待确认申购和拟追加分别表示。T+规则和自然日延迟来自重提取的源条款，源日历须匹配产品开放日范围；不能因币种CNY就给QDII套国内日历。所有未完成买卖单先完成实际敞口确认。

```text
可配置资产估计 = 当前权益 + 新增资金 - 取出资金 - 预计交易损耗
目标价值估计 = 有依据的目标权重 × 可配置资产
目标差额估计 = 目标价值 - 已确认持仓价值
```

这是解释关系，正式订单由执行器计算并在取整后重验。外部资金已计入权益时不能再加一次；赎回款仍在账户内不算外部取出。账户归约及确认规则见 [storage.md](storage.md)。

外扣申购法适用时净额=P/(1+s)，具体费率、金额档、最低单位和舍入规则以已声明条款为准。净值已经包含的管理/托管/销售费用不重复扣；个人申赎、佣金及适用价差另算。市场样例字段不构成真实平台报价。

fee_inspect的document_formats_v2从原始PDF/HTML重提取主体、份额类、币种、渠道、投资者适用范围、费率、持有期、到账规则、限额和精度，重算合同hash。quote_observed_at是必要动态字段最旧的实际获取时点，重新校验不能刷新报价；rule_effective_dates只记录原文明示日期，否则unknown。source_verified只表示文字与数值绑定通过，公开报价不等于账户专属成交承诺。平台“---份”等未知限制按buy/sell_full/sell_partial保留needs_research，不补零；有原文全部赎回权限时，部分阈值未知不自行阻断已证明的买入或全部赎回。有限日累计上限仍须核账户当日已用额度，不能把公布上限当剩余额度。

申购费采用原金额区间及<、≤端点，持有日费阶保留起止日是否包含。half_up_fund与down_fund都按完整申购现金扣原公式费用，份额分别四舍五入或截位，基金承担相应差额；down_fund的share_surplus单列，不冒充费用或退款。down_refund仅在原文规定退款时产生退款，不能利用货币取整多领份额。

赎回由原精度决定顺序。毛额/费用四舍五入规则先按其原精度处理，再确定原费用和净额；净额截位规则保留g=份额×定价NAV，按原公式求contractual_fee，net=floor((g−contractual_fee)/money_step)×money_step，rounding_loss=g−contractual_fee−net。effective_cost相对于合同采用的gross计算；毛额舍入相对未舍入NAV的转移另计，终点使用net。例如原毛额1.005、1.5%费用、净额截至分：费用0.015075、截位差0.009925、到账0.98、投资人执行损耗0.025；零费毛额四舍五入则gross/net可为1.01。不能统一预舍入毛额，也不能用原NAV毛额减effective_cost冒充净到账。

模型执行损耗不改名为实际报告费用。真实确认保留实际毛额、报告费用、现金流和日期，以原规则核验并记录偏差；实际成交份额、同底层总持仓、每批持有期与产品最小剩余份额分别核验。养老金账户款项和未知投资者适用范围不进入普通现金计划的可支配资金。

## 收益与风险

无拆分日总回报：r_t=(NAV_t+d_t)/NAV_(t-1)-1。再投资财富指数为Q_t=Q_(t-1)(1+r_t)；现金分红不再投资的账户要单独累计现金权益，二者不可混用。

```text
回撤 = 当期财富 / 截至当期的财富峰值 - 1
单位净值 = 账户权益 / 当前账户单位数
每期净收益率 = 本期单位净值 / 上期单位净值 - 1
账面盈亏 = 当前资产 + 累计取出 - 累计投入
```

外部资金流按发生时权益单位化，不能计为收益。实际确认晚到时按经济时点重建；信息可得时点仍保留，不能回流到过去决策。没有估值或份额不能声称精确收益率。

波动、终点亏损、持有路径本金损失、峰值回撤和CVaR是不同量。均值回归不是完整分布，经验尾部和压力场景不保证极端风险已覆盖。基金最大跌幅发生日期不同，不能把各自最差值当成真实同日组合表现。

## 证据检查

策略计算、资金/份额取整、独立重算、来源字节核验、签名时点与投资效果分别保存。Quote命中原文不证明解释正确；人工费用映射不证明券商报价；用户提供确认不代表系统认证券商身份。

参考净值金额审计与当前动作的实际定价及终点财富分开。金额排序和CVaR使用同一联合价格/权益目标，逐资产、逐批核对手续费、原现金及应收，必要边界保留原情景概率。费用表自动使用各产品源费档和最低持有期边界的整数计费年龄；这些年龄不是人工赎回日期或下单后经过天数，内部H也不限制持有期。真实样本外记录的预测乐观误差用于当前动作的条件模型校准，不构成历史策略绩效区间。终期净资产不能直接当到账现金。尚未提供当前有效行业上界时，过去季度行业权重只能解释披露，不能证明当前没有某个子行业。

原始输入、可复算结果和规范报告按活动计划保存。修复发生在负责生成或验证的源码，并从原始输入重新生成验证。统计设计模拟使用有已知真值的声明过程评价区间覆盖和检验功效；投资效果仍需实际时间顺序的独立样本。
