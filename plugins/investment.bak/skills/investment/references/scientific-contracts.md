# 全链路科学契约

本契约限定当前唯一EN、联合多期路径、有限政策MPC及CVaR流程，不增加预测模型。模型论文支持方法定义，不证明本插件未来盈利。源码和自动验收必须同时满足下列合同；完整参数与假设见[模型](allocation-method.md)、[训练](training.md)及[前瞻评价](trial-validation.md)。

## 准确性优先与四层精度

准确性、证据和可验证性优先于数量与覆盖。拒绝数、新闻数量、基金数量与覆盖率不作成功KPI；覆盖只声明实际已核范围，未取得或未支持的资料保持未知，不能改写为零值、无新闻或不可买事实。来源缺口可以阻断相应数值建议，但不证明产品客观不可交易。已有真实持仓与风险继续保留，不造冷启动历史、概率或缺失值，不改数据、阈值、seed、置信度或原事实求通过。

| 层次 | 精度与验收 |
|---|---|
| 来源事实 | 原字节、主体、引文、原数字与角色可以重提取；完整源期间与声明粒度一致，不截短日为月/年。事实和推断分列，原文未证明的关系保持未知；[期间合同](news-research.md#源事实与经济内容)保留显式月、季度、年观测 |
| 量纲与时点 | 指标、单位、币种、期间和实际可得时点逐项一致；中文年月日只证明该日，不能补时分、拼接日期或把后来取得改为过去已知 |
| 数值计算 | 对已声明的有限十进制模型数值核验守恒、费用、概率质量、损失、风险及资格排序；精确内部运算不补偿来源错误，也不把序列化模型终值视为无限精度真值 |
| 样本外预测证据 | 真实成熟标签、训练/选择/校准隔离和预登记前瞻评价用于测量预测误差、净财富与风险；不承诺100%预测准确率，未知或未成熟结果保持pending |

成功读取原文只证明取得了该版本，不证明其事实解释、因果判断或预测正确。工程手算、错误注入、性质检查和测试数量只证明对应实现合同；真实来源适配和市场样本外效果须分别验收。没有真实评价时不填写准确率、上涨概率、盈利认证或经理技能结论。

## 本金口径与资格数学

\(B_d=B+d,\;V_d=V+d,\;F_d=B_d(1-r),\;A_d=V_d-F_d\)。
令来源现金路径终值为\(W_H\)，损失\(L=V_d-W_H\)可为负。
尾部质量\(q\)下：

\[
\operatorname{CVaR}_q(L)=\min_z\{z+q^{-1}\sum_s p_s\max(L_s-z,0)\}.
\]

CVaR平移等变性使\(\operatorname{CVaR}_q(V_d-W_H)\le A_d\)等价于
\(\operatorname{CVaR}_q(B_d-W_H)\le rB_d\)。这保持相对净投入本金的既有口径，不改为峰值回撤，也不截断盈利时的负损失。

风险入口将已声明的有限十进制用`Fraction(Decimal(str(value)))`精确表示，内部Fraction继续保留。原PMF先按既有有限值、非负及质量门槛核验，再一次精确归一为`p_i/sum(p)`；同一比较族共用该PMF。全支持共同信息沿用原概率，只有真子组作精确条件归一，递归保持CVaR(c)=c及共同信息节点不变性。

损失以原B、V、d、r及既有序列化terminal_wealth的有限十进制模型估计形成，不先做float相减。生产者使用精确排序尾均值及条件递归，独立证书使用RU变分形式重算风险、预算、资格和有限集合排序；展示字段仍是模型估计，资格和排序使用精确内部值。该精度合同保持原相对本金风险、全局终点损失和费用定义，不换预测模型、不制造情景概率，不放宽预算、置信度或独立验证容差。

普通资格\(\mathcal F\)同时满足来源、交易、现金、暴露、预算及适用校准；普通赢家为\(\arg\max_{p\in\mathcal F}E[W_H(p)]\)。同资金维持免除对自己的净优势门槛；符合已登记风险改善条件的纯减仓也可为风险目标豁免净优势，但仍须满足全部普通风险/校准及源资格。此项是明确风险偏好政策，不认证正收益。来源现金恒等式可证明纯现金维持的零损失，不能伪装成历史统计证明。

当\(\mathcal F\)为空，已登记的恢复政策对合法纯减仓按经验超额\([\operatorname{CVaR}_{emp}-A_d]_+\)优先、再按净利润等确定顺序比较。该顺序是风险偏好政策；恢复eligible=false并保留risk_not_restored，不能据此宣称已满足普通资格。缺合法恢复路径则无当前动作。来源缺口不等于已经证明数学可行域为空。

来源成本满足`fees=path_execution_cost+terminal_exit_assumption_cost`；前者属路径模拟执行，后者属终点仍持有份额的退出估值假设。净财富通过净份额、净现金及净终点估值只扣一次，不能从`W_H`重复减`fees`。毛额舍入调整可有符号；合同手续费、净额尾差和毛额调整分别核验。滚动费预算仍为`recent_actual_fees+max_scenario(full_plan_fees)`的保守预留，并不缩为今天第一笔动作。此核算恒等式和治理额度由源合同、独立现金重建及政策定义支持，[多期交易研究](https://web.stanford.edu/~boyd/papers/cvx_portfolio.html)仅支持比较成本及只执行第一阶段的框架，不证明此额度唯一最优。

正式策略`family.end_at`限定统计复核及当前发布许可，不是基金持有到期、收益H或一年卖出规则；过期、示例和次数耗尽时继续可核新闻/资料并保留持仓风险，无当前订单。族、次数、费用窗口和误差分配属于事前治理政策，[模型选择研究](https://www.jmlr.org/papers/v11/cawley10a.html)支持隔离选择与评价，不授予任何一组常数普适最优性。

## 参数来源与反例

用户确认：本金、风险r及其有效时段、真实追加/撤出、约束偏好。来源合同：费用、精度、最小量、日历、锁定、分配、确认和到账。数据学习：EN系数及训练内lambda/rho、配对残差、成熟样本统计。预登记统计选择：q、置信度、依赖块/窗口、候选族与错误预算。工程政策：菜单稀疏取点、并列顺序、搜索/采集预算、三次重试；这些参数均不是公认唯一最优常数。

信息时点使用真实capture≤原information_cutoff≤review≤decision，publish_cutoff保留检索边界。日期精度和精确时刻遵守相同可得性门槛，缺时分不填午夜；历史决策不能使用后来捕获。当前团队必须为原披露支持的完整共同团队及同一连续区间。

验收反例包括：高收益但超预算维持、正确金额但伪造资格/赢家、遗漏冻结候选、恢复冒称通过、负预算纯现金、基准源不可估、小数追加守恒、run外经济证据、伪造早期预期、日期/时刻不对称、信息封存时钟改写、新任零观察/重任/过期及币种/单位/FX方向错误。修复落在生成、分发和独立验证源码；正式金融事实与生成产物不手改。
