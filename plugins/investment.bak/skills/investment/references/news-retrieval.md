# 近期经济新闻检索与完整原机会域

`retrieval_prepare` 的输入为 `{workflow_id,publisher_discovery_id}`。发布者身份须是同次 `workflow_id + ':publishers'` 已完成的公开 `publisher_discover`。`news_retrieval.prepare` 只产生 CAS 对象，不发网络请求、不另写业务记录；公开操作负责最终不可变验收证明。本版消费已完成发布者时，认证确切请求、输入、独立接受尝试、原子提交及当前代码，重新读取全部来源 CAS 字节核 SHA 和大小，再从原 registry、GKG 分区重建完整检索对象。原发布者首次生产与独立语义核验仍完整执行；显式来源语义审计仍可重放原件。`replay_originals` 参数不再触发消费期重复解析已接受的全部 ZIP，也不能允许调用方注册表或声明替代来源。检索自身的四次完整构建和独立比较仍执行，验证器不写 CAS。

检索域与研究取材集合分别保留。原 registry、机构目录、GKG 每个原文件状态、已解析分区、原 URL/行身份与不支持行保持原样。`complete_opportunities_ref` / `original_domain_ref` 指向这个**完整原已知机会域及其未知项**，不是全球新闻或经济新闻全集的证明。缺文件仍留原文件分母，未知全球及经济相关新闻分母保持 `null`。选择后的 `unselected_urls_ref` 为原 registry 的全部 news/default_urls，减仅实际计划的 `{source_id,url}` 精确键；CAS 对象保留原 registry 引用和完整减集，任何原项均能重建。选中与未选并集等于原域，未选不代表没有经济影响或不可买。

初始取材优先全体本次真实官方机构入口，包括协议尚待证明的主页；主页不因此成为合格正文。所有原 `all_observed_theme_counts` 的机器主题都形成待核经济问题，包含非 web 或暂不支持行的主题；它们没有可用 URL 时仍保持待核问题，不捏造链接。供需、收入、价格、政策、利率、信用、贸易、汇率等机制词只标示机器候选与问题优先级，不能证明事实、收益方向、行业映射或因果。未匹配与无标签项保留 ambiguous 问题，两个问题队列交替服务。不得增加行业、基金、媒体白名单或整体排除体育、娱乐等栏目。

全原已解析行均检查精确 URL/主题。每个问题只暂存至多 192 个不同发布者的提案，按本次身份的稳定 hash 轮转，不按所谓利好强度排名；这是内存预算，未暂存的原行与 URL 仍在原域。已暂存提案按问题轮转与本次计划已选发布者最少次数服务，精确相同 probe URL 只合并网络任务。原文还未取得，不能据 URL 相同认证多个协议、当成多份独立报道，或删除原记录。路径、query、日期和编号不做近似规范化；不做近似语义去重，也不自动判断撤回或事件相同。

版本 `broad_economic_opportunity_retrieval_v1` 的 GKG 实际源请求预算为 192，必须累计失败请求和原 producer 重试。全部官方初始入口预算独立承接原 9 次 producer 重试上界，二者合成总请求/字节/时间预算。0.1.14 在新请求封存前明确声明该预算同时约束初始采集及实际原文链接派生的后续采集，数值上限不变；旧版封存预算不回填。192 是响应时长和内存的版本化工程默认，**没有科学最优性、检索准确率或召回率保证**，也不是语义上的前 192 篇、完整研究机会分母或成功覆盖声明。`selection_batches` 的每批 8 URL 是传输边界；实际重试耗尽时未取得的已选项仍保持未抓/未读，原未选补集不缩小。新 ID 不允许重置同次累计控制器预算。

这类信息检索选择的依据是将尚待回答的经济问题变成可追踪的取材任务，并减少完全相同 URL 的重复运输。经典信息检索教材讨论了同义表达造成的召回问题以及查询扩展的方法，支持核验原文后扩展主体、机制和反证问题这一工作方式；不能把该一般依据外推为本算法或192预算在当前新闻域已验证有效。[查询扩展](https://nlp.stanford.edu/IR-book/html/htmledition/query-expansion-1.html)、[相关反馈与查询扩展](https://nlp.stanford.edu/IR-book/html/htmledition/relevance-feedback-and-query-expansion-1.html)。教材将近似重复识别作为另外的问题，当前实现只做精确 probe URL 调度合并，保留所有原文差异与待核关系。[近似重复与 shingling](https://www-nlp.stanford.edu/IR-book/html/htmledition/near-duplicates-and-shingling-1.html)。发布者分散、机制词、稳定 hash 与交替调度仍是未经当前真实域审计的工程启发。

后续公开 `news_collect` 继续使用完整原 policy/registry/groups，按已封存任务取得原文并沿原规则核验正文、发布时间、取得时点和引用。宿主阅读实际进入本次评审的完整合格原文，核验经济机制、事实与推断、冲突及修订；从有证据的正文继续拓展主体、机制与反证资料，所有尚未处理任务具体保留。预算结束只能报告部分取材和缺口，不能声称完整经济新闻覆盖、全球多数或量化验收通过。原基金实时目录与完整同类比较分母、真实持仓/订单/在途、费用合同、严格历史 EN 与独立校准门槛均不改变。

列表原字节解析出的同来源正文或分页链接，须先封存派生任务，再调用公开采集。PDF 附件同时重新取得父正文与附件，二者均收费；每个任务绑定原父捕获、来源、窗口、原请求及累计预算。聚合验证器从当前原字节重新提取链接，核真实子操作的接受和提交回执、封存先后、全部失败/重试费用及未完成链接。派生任务只补接已有研究问题的取材，不修改原问题、原初始选择或未选补集，也不授予覆盖或投资资格。

结果计数分别说明候选/ambiguous 元数据行与精确 probe URL、全部原已知 URL、选中、未选、未抓/未读、失败或未解析原文件；原文抓取数在规划阶段为0，事实/PIT/交易资格始终为 false，准确率和召回率保持未知。要评价检索质量须另有预登记、可重放抽样和真实原文评审，声明仅限审计设计支持的范围，不能以抓取数量、拒绝数或自哈希一致充当有效性。
