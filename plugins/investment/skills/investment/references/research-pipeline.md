# 原始净值准备、操作世代与审计

公共研究产物为 schema4，插件版本仍为 0.0.1。正式日常流程的代码和 identity_snapshot_ref 来自当次目录与身份发现。research_prepare 经统一入口验证当前来源；内部 prepare 必须显式接收 store、operation_id、identity_snapshot_ref，可接 context，不直接建立真实账户。

一次 1–50 个不同六位代码、lookback 至少覆盖 120 个净值区间及明确研究期/期限是工程边界，不是市场覆盖或统计充分条件。研究限定已核实人民币场外净值口径，未知/外币/场内身份不能借统一币种进入计算。

```text
当前请求/源码指纹 + 有效租约世代
 → Store 私有 attempt 目录
 → 在线原文字节、捕获链、当前目录及身份文档
 → 原始行动全表、净值、基本特征与成熟/待成熟标签
 → 分片与清单
 → research_audit 从原文独立 Decimal 算术复核
 → 再验租约所有权，由唯一编排器事务发布引用
```

运行地址为计划内 work/<operation hash>/<generation>/<unique attempt>/<run id>。旧世代不能继续发布，新世代不复用旧世代仍可写目录。同一已提交公共请求由 Store 返回并复验封存结果；尚未提交的失败重试新建独立 attempt。输入和实现变更需要新请求，不修改历史封存数据凑检验通过。

捕获保存 HTTPS 来源及逐跳、媒体类型、编码、原文与文本摘要、取得时点。source_documents 对文本 HTML/PDF 保存可定位抽取；审核重新读取原始字节并重新抽取。图片/OCR不足时给出 needs_review，不把无文本的 PDF 当字符串使用。跨归档复制原文字节保留语义身份，物理路径变化不改变文档身份。

source-actions.json 与 manifest.action_inventory 保留本次来源完整行动表，包括未来除息日已披露记录、record_date、ex-date、cash_payment_date、原披露份额单位、每份金额、known_at 和来源。币种从同份额经验证身份交叉绑定。未披露申赎登记资格、投资者分红方式或未来公告覆盖时保持 unknown；缺记录不证明未来没有分红。拆分/折算缺少完整份数变换支持时阻断相关研究窗口，不能假定 share_factor=1。

现金权益、支付到账及再投资分开。净值标签是现金分红权益市场研究，不能冒充实际投资者收益。实际账户需要登记资格、支付及分红模式对账，执行可支出现金由账本决定。当前费用页也不能回填历史交易条款。

基本市场特征来自过去观察；当前经理、公司、费用和新闻不回填历史样本。统一数值运行器绑定自然日决策、资料年龄、源定价日和共同终点，再构建完整净值与分红现金路径，覆盖定价、确认、到账和下一次配置。每条路径保留原始逐日观察、成熟日期、身份和来源版本，不用两端价格插值。联合样本外路径用于固定多期政策族的误差校准，不能将当前候选情景改名为历史策略收益。期限、成熟条件及因果测试见 [allocation-method.md](allocation-method.md)。历史发布时刻未完备、幸存者与历史平台条款仍是公开限制。

完成封存与审计后，逐捕获将原始NAV字节引用、原取得时间、同次行动证据和原运行绑定发布到计划内的已验证基金主体索引。下一次研究按索引读取有界历史，核对原清单、字节、身份、时点及行动上下文，再导入真实版本；不扫描无界工作目录，也不将当前重取时间改成过去发布时间。未封存尝试不能进入历史可得性证据。全部版本均从各自原始字节重建；首次观察之前的历史仍只能采用明确标记的条件代理。

本地NAV证明采用无损gzip，压缩字节与原始字节分别校验摘要、长度及解压边界，原取得时间不变。原字节推导的日期范围用于跳过与请求窗口不相交的捕获，选中范围再次从原字节核验。单次上限为每主体1024条索引、64 MiB采集与压缩证明字节及180秒；到界返回明确资料不足，不能截断后宣称完整。原封存运行目录必须随历史保留，不能只保留索引而删除证明。

同次研究的全部主体索引在一个带租约所有权校验的事务中提交；中途失败整批回滚，未被引用的不可变原文字节不作为已发布历史证明。

审计分别核对源码/产物身份、捕获链、代码与份额身份、行动表、跨日原捕获及独立净值/标签算术。此类可重现性不证明原文真实性、完整市场覆盖或投资优势。存储上限与归档见 [storage.md](storage.md)。
