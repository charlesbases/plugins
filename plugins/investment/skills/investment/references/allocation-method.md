## 账户与风险

```text
B = 原确认本金 + 已确认外部净投入
V = 当前现金 + 份额价值 + 经济应收
r = 有效相对本金亏损容忍率
d = 独立假设追加
F_d = (B+d)*(1-r)
A_d = V+d-F_d
```

盈利、赎回与风险偏好变更不重置本金和已有亏损。真实新增/撤出由确认事件修改；假设d不修改账本。零追加当前方案与每个d的同资金维持基准分开比较，不因本金越大绝对利润越大而自动追加。

令policy包含源精度当前动作和非预知后续现金规则，W_H含现金、NAV、正确登记权益、除息应收、支付及费用：

```text
max E[W_H(policy,d)-W_H(hold,d)]
L_H = V+d-W_H(policy,d)
共同粗化风险分区下的经验终点 CVaR_q <= A_d
```

q是尾部概率，不是r。风险评价与政策观测分开：当前风险分区仍粗化为所有情景共组，规则只使用滞后可见前缀，不宣称真实全信息时间一致性或未来损失保证。来源压力没有人为概率；历史映射风险诊断不是今天条件风险分布的置信上界。

L_H可为负，不截成零。由CVaR平移等变性，CVaR_q(V+d-W_H)≤A_d等价于CVaR_q(B+d-W_H)≤r(B+d)，无需另换风险口径。r是用户偏好，q是尾部质量，统计错误预算alpha是校准参数，三者独立。

风险计算按[科学契约](scientific-contracts.md)将原B、V、d、r及已序列化W_H解释为有限十进制的Fraction；W_H仍是模型估计。原情景质量先核验、再一次精确归一为PMF，完整信息组不重复归一，真子组才精确条件化。损失、尾均值、递归预算、资格和排序在内部精确比较，证书以独立RU形式重算；展示字段仍是模型估计，资格和排序使用精确内部值。源费用、全局终点损失、本金及统计参数保持原义；精确计算不保证预测或市场结果准确。

普通资格的维持方案与调整方案都须满足预算、现金、暴露、来源和适用校准；维持仅免除与自身比较的净优势门槛。纯现金维持可通过原始现金守恒证实确定性零损失，不伪造历史校准。没有普通可行方案时，合法纯减仓可进入单独risk_recovery，按max(0,经验CVaR-A_d)的超额优先、再比较净利润等已登记规则选择；ordinary eligible=false，risk_not_restored。恢复顺序是明确的风险偏好政策，非唯一数学最优定理或未来概率保障。无法核验合法纯减仓则risk_unresolved，无当前订单。

## 资金状态与政策类

现金簿分available、reserved、sale/dividend receivable；买入预留整个金额，退款只在确认条件下释放；卖出按源定价与批次费用形成应收，正常确认后保守源延迟只作估值假设。真实可支出余额由feedback确认，不从预测到账时点写入真实账本。

既有已确认应收款由快照逐笔保留身份、金额、种类和原到达时钟。模型先提交当前动作，再按到达条件将应收转为后续可用现金，并从未到账余额中移除；不重复增加财富或支付。日期级资料只支持日末可用，未知时钟须补核。模型预计到达与真实到账反馈分开。

既有分红与模型中的已登记权益必须有明确来源身份关联；同资产已登记权益的编号不一致时，保留真实应收款并要求补核，暂停该路径金额比较。不能按金额或日期猜测同一笔分红，也不能将可能重复的权益再计为收入。以后登记的新权益独立处理。

原有已确认现金可在源截止时间前同日申购：当日定价与份额处理先于登记权益。仅有当日确认或到账日期、不知道小时的资金，估值规则等待至日末提交，再由产品日历确定下一开市定价；不假设上午已经到账。未来限额只使用至少上一日、满足声明净值延迟的可知价格，不读取当天未披露收盘NAV。

比较可以含满仓卖B后再配置C的价值，未来规则只用届时现金/前缀状态，不用未来实现值挑选。不能凭原样本唯一前缀识别未来终点。当前共组只定义经验终点CVaR的粗化风险评价，不限制合法的滞后价格反馈，也不证明完整动态条件CVaR。交易/确认/到账日不相同，缺对应原价格/日历不假造。

allocation.build_source_actions是唯一当前动作生产者。买入为含申购成本的cash_debit，卖出为真实lot_id/shares，金额不代替份额。金额/份额按来源格点与最低量、剩余额、锁定及允许批次生成：每维不超过16点时取完整来源格点，否则按声明规则取端点、四分位与费阶边界邻点；在模型外样本误差前冻结全部有限组合及后续规则。current_action_scope_complete只描述这一声明有限集合；source_precision_domain_complete另列是否穷尽全部来源格点，均不证明全市场/全投资最优。

只有完整计算的有限族参与portfolio_mpc.optimise；它按整条确认、退款、登记、到账及后续现金路径的期望扣费净财富排序，再按风险、费用、全路径换手与稳定id处理并列。当前动作或policy数量超预算返回partial及所需预算，不保留未完成的incumbent。来源未证明的当前日剩余申购额度、部分赎回门槛或多批费用/金额舍入方式，作为具体补核项；不借旧连续金额或固定费率路线补齐。

完整性逐资金组判断：某追加组超预算不影响完整零追加组。funding_registry/hash及各组policy_count_upper在所有结果之前封存；上界由源动作菜单、合同费档、锁定和到账窗口推导，未完成组无best且继续占用预登记错误预算。

source_local_policy_v2局部决策日与价格/会计网格分开。候选延后日由来源锁定结束、下降费档和可再投资到账窗口生成，先冻结再读结果；每条规则仅用届时前缀信息。全路径比较费用节省、等待涨跌和再投资机会，不预知未来价格选择日期。费用诊断年龄由源费档和锁定边界自动生成；等待策略不生成今天的未来订单。[多期优化/MPC](https://web.stanford.edu/~boyd/papers/cvx_portfolio.html)支持只执行第一步的滚动结构，不证明预测有效。

当前发布只有零追加的第一阶段订单。后续真实确认与新信息到来重新分析，假设未来换入不成为现在的购买承诺。

每条用于比较的现金路径均执行独立参考验证：从合同、批次、源日历和人民币舍入规则重算费用、净额及到达时钟，连续重建现金/冻结/应收余额，核对每笔状态变化、权属和唯一到账。参考费用及日历算术不调用生产报价函数作为唯一判据；错误注入检验验证器会拒绝费用、净额、时序及重复支付错误。

现金需求为planning.cash_deadline_days及cash_required_amount；从当前decision_at派生截止日T。每条点/选择情景在T已到账且未占用现金须≥所需金额。H原收益终点保持；H后只处理有原定价及到达时钟的已有订单/应收，不假造新NAV或现金。缺覆盖或不足时无合格方案，基线及减险也不能豁免；此约束在通用现金验证之外追加检查截止日余额。

当前条件赎回类以源合法节点上的净变现额与封存已知持仓估值加当前申购投入作零增益比较，ge/le两方向均仅为候选。初始申购确认后才使用由该情景真实模型成交NAV产生的份额；再投资不加入原目标。该基准是明确的可观测经济边界，不是未来EN延续价值或唯一最优停止定理。选择仍来自同资金完整政策净财富及风险、源资格和独立校准；没有未来新闻输入就不假造它。

预计路径执行费为sum(p_s*path_execution_cost_s)，各赎回年龄质量由首次条件满足时点自然产生；期内无卖出则本期赎回费为零，不表示终身退出免费。终点退出估值成本另列，不冒充已发生或预计路径成交费。

## 暴露、成本与校准

底层法律基金的投资人资本份额与行业现货证券gross/NAV分别处理。行业上界须来自有效合同/正式行业主体证据，可大于1；unknown不是0或1。未知正持仓不能被宣称满足配置行业上限，清仓/补核范围真实记录；衍生名义风险没有来源时另标未知。

来源费用按两种生命周期范围分列：`path_execution_cost`是路径上已模拟发生的申赎有效成本；`terminal_exit_assumption_cost`是评价终点仍持有份额按声明退出估值假设计算的成本。`fees=path_execution_cost+terminal_exit_assumption_cost`，同一条现金路径的净终值`W_H`通过净申购份额、净赎回款及终点净估值各扣一次，不能再从`W_H`减一次`fees`。两个成本分项用于解释和预算，并非额外现金扣款；终点退出估值不成为真实订单。原始毛额与来源舍入毛额之差可带正负号，合同手续费、净额截位和毛额调整分别核验，不能将带符号毛额调整强制截为非负。

滚动费用上限继续采用保守政策：`recent_actual_fees+max_scenario(fees_of_full_plan) <= maximum_rolling_fee_amount`，全计划包含未来模拟和终点退出假设成本，不因当前只执行第一步而缩小预留；真实反馈费用按原回执计入实际窗口。此保守额度规则是治理选择，不是预测收益或唯一科学最优费率。

申赎费按实际金额、每批起止、锁定、基金总最低份额、费用阶梯和来源精度计算。FIFO/LIFO等批次分配须有来源依据；同基金多个lot属于一笔赎回请求。不同批次费用及gross/fee/net舍入是否先分批再汇总，不能由年龄费率或最低份额反推；缺原文规则则相关组合或终点赎回不可估成精确值，保持来源缺口。已知本金事实和mark目标的现有持仓估值仍保留。合同收费与份额/净额尾差分列，真实反馈收费不被模型有效成本改写。费用诊断只使用各产品源费档及最低持有期边界的整数年龄，没有年龄费档时只用来源最低年龄；用户不填写赎回天数，内部H不限制持有期。NAV已含运营费、历史已支付费不再扣。普通动作覆盖扣费净优势与误差缓冲，反向动作更高门槛，滚动实际费用预算保留；风险恢复另列，不豁免源交易、现金或暴露约束。

trade_policy.kind=forward_oos_path_policy_error_v1，family.method=joint_block_maxT_fixed_review_family、candidate_rule=source_settlement_mpc_policy_v1。正式当前统计决策须为`registration=declared`，复核时刻同时满足`family.start_at <= decision_at < family.end_at`和`1 <= review_index <= max_reviews`；示例及过期/耗尽族只继续新闻和资料研究，保留持仓风险，无当前订单。`family.end_at`约束复核与发布许可，不是基金持有到期、收益H终点或一年卖出规则。经济门槛、样本窗口、时序依赖、种子、置信度与计算预算事前冻结；illustrative不能授予交易资格。独立原OOS predicted/realized完整路径对逐policy重算乐观误差及本金损失，不把当前情景当历史策略收益。

普通盈利调整适用净优势门槛；已满足来源、校准及预算的纯减仓，若按登记minimum_risk_reduction_amount改善超预算维持，可为风险目标豁免净优势，仍可属于普通可行方案。未达到普通资格的经验恢复才标risk_recovery/eligible=false；两者均须真实费用、现金及暴露合格。

## 金额配对研究

numeric_mpc及最终复核调用decision_validation：独立从原资金/路径/冻结候选重算CVaR的RU变分形式、预算、资格、处置完整性及有限域argmax，不调用生产资格/排序函数。family-selection另核同本金的普通优先、恢复超额优先顺序。来源缺失或无可估维持基准的资金组不发布不完整比较，其他完整组继续；这不认证未知源分支可执行或全市场最优。

news_wealth只重放显式登记的研究账户。原生NAV与完整资产/新闻协变量块使用同一资本、费用、时钟、候选和原始外样本；该比较不隔离新闻因果。六个终点坐标只支持current_action_then_hold子集；full_source_mpc需要登记的多日期EN成熟训练帧，重建拟合/路径后评价同一完整有限策略族，不插造中间价格。当前条款重定价与真实历史条款分开标记，研究资本不是实际用户账户历史。

仅有调用方JSON、时间和自哈希可计算conditional_currency_replay_ready的工程算术，不能授予strict PIT。source_replay_ready须由内部验证边界读取、重建原始来源产物。回顾研究可现在登记并明确后验选择局限；不能补写旧的前瞻登记时间。逐原点CVaR来自同H预测情景；单点退化CVaR标no_residual_risk_evaluation，允许盈利时负损失。实际路径报告最大回撤及回撤尾均值，日期不充作独立情景，研究算术不证明生产多期优势或可盈利。
