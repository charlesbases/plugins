# 模型训练、效果检验与启用控制

本页以下命令保留原有单基金条件研究基线。新增的账户调仓、可选追加资金、Elastic Net总回报预测、CVaR优化及逐日时序检验，统一按 [allocation-method.md](allocation-method.md) 执行；旧基线结果不能认证新策略。新增命令成功只表示计算完成，不升级真实投资资格。

## 安装版入口

```bash
python -B <skill-dir>/scripts/model.py validate-all --root <root> --plan <plan> --codes <codes...> --start YYYY-MM-DD --end YYYY-MM-DD
python -B <skill-dir>/scripts/model.py train --root <root> --plan <plan>
python -B <skill-dir>/scripts/model.py verify --root <root> --plan <plan>
python -B <skill-dir>/scripts/model.py predict --root <root> --plan <plan> --research
```

占位符须替换。validate-all从资料准备运行到完整模型实验；train消费已核验资料。模型入口及固定统计依赖要求Python3.12+，首次安装需访问PyPI；基础净值准备仍支持Python3.10+。依赖缓存位于同一root/runtime，不改系统解释器。verify复核保存产物、参数、分割、CV误差、预测、校准和回放。默认predict拒绝不合格候选；--research只输出明确标注的条件预测，不能作为买卖推荐。

退出码0表示验证/诊断命令执行成功或候选通过全部门槛；2表示实验全部执行但候选被拒绝；1表示操作失败。不能只凭退出码或训练完成宣称投资有效性。

## 冻结实验

使用已核验的真实净值及过去20/60/120观察区间收益、60区间波动和回撤。净值日期后两自然日作为保守可得性代理，随后第一个有净值的工作日作为申购价格代理；二者均不是观测到的发布时间或历史可买性。该时滞参考普通开放式基金次日披露义务，异常延迟与渠道同步仍须另证。未来净值只用于构造结果，不进入X。

名义研究条件为申购0.15%、赎回0.50%、到账延迟3自然日、研究金额10000。它们是明示假设，不是回填到历史的天天基金报价或账户本金。费用后净收益、终点损失、本金路径损失和峰值回撤各自建模；管理/托管等净值内费用不重复扣除。

按唯一决策日期60%/20%/20%分为训练选参、校准和最终测试；每个边界按label_available_proxy清除尚未成熟标签。训练区内部三折扩展前向验证，ElasticNet使用固定9组alpha/l1组合；仅用训练段拟合标准化。每日期、每底层组合等权，不能将同组合份额当独立证据。收益、终点损失和两种路径风险按30/60/90期限分别拟合，共12个目标。

参数网格、时间分割、费用情景和验收阈值在拟合前保存；最终测试不参与选择参数。动量、波动、回撤消融只用验证段，不根据最终测试改模型。所有尝试、参数和结果留存。同输入、代码及依赖的已完成实验复核后复用；失败恢复保存原阶段。不得把反复运行同一测试当新增独立证据。

## 风险和策略验收

80%/90%区间由独立校准段的加权残差得到，报告最终测试覆盖、宽度、上下尾超限和分位损失。日期面板按期限分块，500次固定种子重采样计算近似95%区间；至少8块才允许优势判断。覆盖偏差容差为10个百分点，且置信下界须达到名义覆盖减10个百分点。此为预先声明的研究门槛，不能解释为所有市场通用保证。

均值优势须相对训练均值和零收益基准的误差改善95%下界大于零。策略对申购0/0.15%/1.50%、赎回0/0.50%、到账0/3/7自然日共18情景回放，比较模型选择、周期等权、等权维持和各单基金维持。决策只使用冻结预测，包括期末标签尚未成熟的预测；这些actual保持空值，不能因结局未知而删掉当时可作的决策。

每笔预留、买入、分红权益、卖出和结算检查现金/财富守恒；在途资金不可重复使用。期末未平仓按最后已知净值计价，不虚构成交。策略优势要求日期块改善下界为正且优于维持基准；证据太少与明确落后分别记录原因，均不允许启用。

严格历史交易资格另行核查真实费率、可买性、确认、到账、历史候选和时点数据。缺少这些证据时该项判失败，其他条件研究照常完成。任何一项必要门槛失败都使候选rejected。完整执行不等于全部通过，测试不能保证收益。

## 可复算及存储

源码包含model.py、model_stats.py、model_scenarios.py、model_verify.py及依赖锁。参数为可审计JSON，不加载pickle。独立验证器重建分割、标准化、加权ElasticNet最优性条件、所有CV参数/误差、校准分位、预测归属和区间；由复算指标重建验收，不信任保存的passed字符串。

样本、预测、策略预测、逐笔回放和每日财富按时间分片；文件清单独立存JSONL，主清单小于1MiB。记录资料、政策、源码、依赖及文件哈希。所有产物归当前root/plan，model_validation通过共享索引入口登记；保留真实账户和旧模型状态。代码修复必须进入插件源码，经安装版重跑后使用，不能手工改产物让验收通过。

方法参考：[ElasticNet](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.ElasticNet.html)、[StandardScaler](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.StandardScaler.html)、[基金信息披露规则](https://www.csrc.gov.cn/csrc/c106256/c1653985/content.shtml)。方法有依据不代表本模型具备收益优势。
