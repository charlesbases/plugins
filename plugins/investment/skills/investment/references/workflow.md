# 决策流程与基金评判

## 账户起点

核对最新已确认持仓的份额类别、份额、成本、日期、费用和分红，以及未确认订单、可用与在途现金、追加与取出。历史建议不是成交，当前金额估算不是确认份额。没有关键数据时说明能分析的范围。

沿用用户已确认的截止日和风险口径。追加资金是否共享原期限没有约定时标为待确认，不自动重启期限。区别可承受损失、模型压力损失、实际亏损与峰值回撤。

## 信息采集和质量

新闻采集统一执行 [news-research.md](news-research.md)：正式来源、专项核实、未持有机会扫描、原文状态、增量位置及缺口验收都在该文件维护，不另设来源表。账户记录异常或模型未就绪时仍可独立核实新闻，但不能编造实际仓位、资金或预测。

检查重复或缺失日期、异常跳变、单位、币种、分红/拆分、类别和基准。极小债券回撤注明净值精度与样本限制。规模区分类别、整个基金及目标ETF，并标报告日。

## 事件分析

用新闻规范中的事实、实际暴露、影响路径、反证、价格及成本证据链形成品类判断。事件关联不能替代因果与替代解释；资料缺失不编造数字化置信度。官方声明、已经发生的效果和预测影响分别处理。

历史相似事件只提供情景参考，不能证明本次复制。未经核验的预期差、新闻热度或最近涨幅不是已验证交易信号。

## 基金评选入口

使用 [fund-selection.md](fund-selection.md) 的新评选规范：平台准入、底层组合分组、分类指标、模型状态、同类评分、独立组合配置及降级。该文件是评选方法的单一来源；这里不维护另一套评分表或固定因素占比。

## 行动和目标仓位

| 动作 | 需要的依据 |
|---|---|
| 维持 | 原理由仍成立，或交易的费用后优势不足；说明评估过什么 |
| 加仓 | 追加资金配置、恢复有依据配置，或可靠的增加风险依据；未知预期收益不是确定优势 |
| 减仓 | 期限、资金需求、风险预算或暴露不匹配；说明减仓前后风险和成本 |
| 引入新品类 | 事件与产品暴露相关；比较新增、维持及减持原仓的费用后意义、重叠和集中度 |
| 更换产品 | 确定的成本、跟踪、风险或交易优势足以覆盖更换代价 |

解释推荐与其他方案暂不优先的理由。缺证据可维持、暂缓或仅关注，不为每日分析强行交易。明确产品风险或资金需求不必等待盈利预测才处理。

目标比例按 [fund-selection.md](fund-selection.md#组合层与交易决策) 的独立组合层产生，公开目标函数、输入、约束、参数来源和敏感性。资料或风险口径不足时列候选与风险取舍，不以经验比例补齐模型输出。用户明确指定比例时可以核算执行金额，注明这是用户配置而非模型优化。

风险预算可比较压力配置，不保证实盘亏损上限。压力参数注明历史或持仓依据，未经校准者标为假设，不独立据此决定实盘仓位。未定义的止损、行业上限与缓冲比例不冒充已确认规则。

按 [allocation-method.md](allocation-method.md) 同时比较内部调仓、追加、混合与维持，再按 [financial-analysis.md](financial-analysis.md) 校正金额。不预设追加优先，不因投入更多、预计利润金额更大而排在前面。每项增持必须给完整资金腿；目标配置与当前可执行动作分开，待到账或待确认追加的买单只列计划，到账后重新评估，不重复下单。缺少关键依据不生成正式精确增风险金额。

## 效果检验

成交后更新记录，保留当时可得的信息、判断、模型版本与执行差异。与同现金流、同交易规则及费用口径的维持方案比较费用后收益、回撤、换手和到账，不只展示成功案例。

数据校验、历史回放、校准、样本外和实盘是不同层级。训练数据、标签成熟、时间隔离、验收及模型状态按 [training.md](training.md) 执行；理论或算术检查不能代替投资效果验证。

## 理论来源

- [SEC资产配置](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)：支持期限、风险与分散配置，不证明固定比例最优。
- [FINRA市场择时](https://www.finra.org/investors/insights/market-timing)：说明成本与错过行情的风险，不证明具体策略成败。
- [GIPS收益计算](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/)：提供现金流与收益口径参考，采用公式不代表通过合规认证。

理论支持流程设计；具体交易仍需当前事实、账户和可复核判断，理论链接不能替代交易证据。
