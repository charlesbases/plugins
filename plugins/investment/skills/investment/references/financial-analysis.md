# 可复算财务分析

## 能力与应用场景

检查并使用宿主实际提供的Python或电子表格等工具，运行计算并核对结果。无工具时交付计算方案并明确未执行，不伪称调用专用理财功能、商业行情终端或Excel加载项。

| 能力 | 应用 | 证据 |
|---|---|---|
| 财务建模 | 持仓、现金流、费用、金额和期限关系 | 输入、公式、假设、结果、版本及检查 |
| 情景分析 | 不同收益、风险、利率或流动性假设的后果 | 参数来源、暴露、多个情景及敏感性；无依据不附概率 |
| 方案比较 | 维持、调整、更换或新品类的费用后意义 | 相同口径、交易约束、取舍与资料缺口 |
| 效果验证 | 检查方法是否产生费用后优势 | 时点数据、参照、样本外和实盘，标明未完成层级 |

DCF适用于经营现金流和估值假设的企业研究，不默认用于指数基金或黄金价格预测。财务能力不证明预测可靠。[OpenAI财务分析用途](https://learn.chatgpt.com/use-cases/collections/finance)

## 数据与假设

保留来源、查询条件、获取时间、截止日、单位、币种、分红口径、缺失值与核验范围，以及允许留存的原始快照/导出和公式/脚本。校验值证明文件一致，不证明数据正确。

区分原始、用户提供、计算、估算及情景假设。来源失败不填零，缺数据不插值伪装完整，不生成随机数据冒充行情。第三方数据只核对了部分官方点时明确范围。

新闻证据与时间口径统一按 [news-research.md](news-research.md)。核实发布内容不等于已确定收益影响；传导路径和压力参数仍分别标为推断或假设，不把新闻热度变成任意收益率、概率或仓位。来源缺口导致关键输入缺失时暂停依赖该输入的计算，独立计算可继续。

比较采用共同窗口、日期和分红口径。年费条款合计不等于完整审计费用率，跟踪误差合同上限不等于实际指标。

## 金额与资金校正

V为当前账户总资产，包含现金与正确计价的在途资产；A/W为估值后新增/取出的外部资金；C为预计交易损耗；H_i为当前已确认持仓价值；w_i为有依据目标权重。

```text
可配置资产约为 V + A - W - C
目标价值 T_i 约为 w_i × 可配置资产
目标差额 D_i 约为 T_i - H_i
```

A/W已计入V时不能再加减。D_i不一定等于申购申请金额或赎回到账：校正费用、未确认订单、最低单位与到账。净值不是锁定成交价，预计比例和金额标为估算。权重连同现金和其他资产核对，不把同一在途资金计算两次。

仓位输入来自 [fund-selection.md](fund-selection.md#组合层与交易决策) 的合格组合结果或用户明确指定配置。这里负责金额与资金核算，不用计算公式重新发明评选或经验仓位；算术正确不证明权重合理。

组合求解及跨预算比较的唯一数学定义见 [allocation-method.md](allocation-method.md)。可选追加记为proposed_contribution，只进入假设方案的预算；未到账不得叠加到真实V或可用现金。不同本金方案同时报告扣除追加后的利润、收益率、绝对尾部损失、费用和增量资金；不能把增资当收益或用更大分母掩盖原仓风险。无投入额度/偏好时保留前沿，不能使无上限预算的收益最大化问题冒充有唯一解。

## 收益、回撤和跟踪

NAV为单位净值，d为当日每份现金分红。拆分/合并需正确调整，无法处理的序列暂停计算。

```text
无拆分日总收益 r_t = (NAV_t + d_t) / NAV_(t-1) - 1
财富指数 Q_t = Q_(t-1) × (1 + r_t)，初始为1
窗口收益 = Q_end / Q_start - 1
DD_t = Q_t / max(Q_start ... Q_t) - 1
窗口最大回撤 = min(DD_t)
年化波动 = 样本日收益标准差 × sqrt(声明的年交易日数)
```

分红再投资与现金取出区分。净值已含运作费用，历史回放不重复扣管理、托管和销售费；个人申赎与佣金另处理。窗口回撤不是成立以来回撤，也不是未来亏损上限。

跟踪误差为基金与对应基准日收益差的标准差年化；偏离注明日均或区间收益差。没有正式基准数据不计算正式指标，代理基准写明构成与假设，不称基金公司披露值。价格指数不含股息时正偏离不直接称经理超额收益。

账面盈亏=当前资产+累计取出-累计投入。策略表现按外部现金流前后估值分段计算再几何连接；缺估值不能声称精确TWR，近似方法注明误差。有真实日期现金流时可另报XIRR/MWR，不能与TWR混用。赎回款仍在账户不是外部取出。

## 费用、情景和回放

外扣申购法适用时净申购额=P/(1+s)，申购费=P-净申购额，具体以条款为准。赎回按实际批次、持有天数、份额和净值计算；类别字母或优惠宣传不代替条款。

恒定金额运作费粗估为P×费率×天数/年天数，注明近似、其他费用和目标ETF免重复收费，不称实际账单。更换比较剩余期限的费用改善与申赎、价差、在途暴露等成本。

静态情景组合收益约为sum(w_i×r_i)。说明r_i为净值收益或费用前收益，防止重复扣费。各资产历史最大跌幅可能不同日，不伪装为真实组合同时损失。波动与相关性变化，正态或低历史波动不能覆盖尾部、违约和流动性风险。

历史依据、经济推断、人为压力假设分开。未经校准不附概率、不独立用于实盘仓位；风险预算约束模型分析，不保证止损价格或实盘损失。

预测分数和概率的资格以 [training.md](training.md) 的模型卡、校准和验收记录为准。Elastic Net均值预测不等于收益分布；终点亏损不等于持有路径本金损失或峰值回撤，不混用风险标签。

持有回放声明交易、再平衡和现金流假设。新闻回测使用当时可得信息及实际开放日/确认规则；单年比较、局部核验、合成情景与样本外测试分别报告，不因运行Python就声称策略有效。

## 检查与交付

核对日期、分红/拆分、单位、权重和资金恒等式、重复费用、公式引用和代表性结果。人工例子或独立计算用于核对关键公式，不能只验证文件能打开。

保留可编辑输入、公式、来源和假设，可另生成只读摘要。统计值、原始数据与复算过程共同交付；持久资料默认按 [storage.md](storage.md) 写入 `$HOME/.investment/` 的活动计划目录，不进入可分发插件源码。大型输入分基金、月份和文件分片，日常按索引读取相关窗口，不将全历史一次性载入模型上下文。
