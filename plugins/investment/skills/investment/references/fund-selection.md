# 基金评选与评分规范

## 范围与执行状态

这是技能执行的评选规范，替代旧的泛化评判表和经验仓位默认退路。插件附带 [资料准备入口](research-pipeline.md) 和 [训练、预测检验及策略回放入口](model-validation.md)。执行器、现场拟合参数、条件研究结果与可用于投资建议的合格模型是不同产物；未通过数据和效果验收的候选必须拒绝启用，不提供宣称有效的预训练参数。

每次评选先读取活动计划的最新平台、币种、资金、单笔持有期、流动性和风险口径。平台选择属于账户输入，不是通用固定评分因素。用户改用天天基金时，用其公开资料及真实可核实的销售条款，不沿用支付宝折扣或可购买结论；不登录或代交易。资料不足时说明缺口。

模型卡及产物按 [training.md](training.md) 核验：

| 状态 | 允许输出 |
|---|---|
| untrained / training | 核实事实、计算条款费用、列候选及取舍；预测分数和概率为未评分 |
| validated | 仅在模型有效类别、期限、平台/费率场景及数据范围内使用经核验预测 |
| invalidated | 停用旧预测，说明过期、漂移或覆盖不匹配原因，降级为透明比较 |

无法核验产物、验收或本次输入匹配时，按未评分处理，并按 [training.md](training.md#自动首次流程与重训触发) 自动推进首次准备/训练或重训检查，不只以“无训练数据”为由结束。不得信任单独的validated文字。账户未定义风险口径或效用参数时，可展示收益—风险候选前沿，不冒充已确认个性化最优解；这不阻止公开数据准备和独立研究训练。

## 候选池与准入

建立平台实际可买的份额清单，记录覆盖数、排除数、未知状态数、日期、来源和遗漏。有限覆盖只能称候选范围内选择，不能称全市场最优。

1. 先核对申购/赎回开放、限额、最低金额、持有与锁定期、交易日历、确认及到账；不可执行或与期限冲突的产品剔除，状态未知者保留待核标记，不进入可执行推荐。
2. 按fund_group_id识别共享组合的A/C/I等份额；组合质量不因份额重复加权。份额费用、客户资格和可买性仍分别核对。
3. 按实际用途和暴露分组：指数按同标的；主动权益按风格/行业；债券按利率/信用、久期和含权程度；黄金、海外及其他品类独立比较。类别名称不能替代持仓穿透。
4. 检查资料质量、重大运作限制与已核实风险事实。缺失不填零风险；新基金或新经理资料不足单独标记，不编造历史。

余额留存是组合决策。用户排除现金管理产品不意味着必须将余额全部买入基金，也不自动排除普通债券基金。

## 分类指标与公司经理

新闻与公告的来源、版本、核实状态及缺口统一按 [news-research.md](news-research.md)；此处只维护基金评选方法。未核实线索不作为增减仓依据，新闻不能直接生成预测分数或配置比例；已核实交易限制和风险事实可按准入及风险规则处理。

| 维度 | 可核验变量及用途 |
|---|---|
| 短期总成本 | 按实际金额/持有天数核算申赎、销售、佣金/价差及资金在途；区分费用场景和真实报价 |
| 指数实现质量 | 同基准实际跟踪偏离/误差、现金影响、复制与运作变化；合同目标不作实际指标 |
| 主动管理质量 | 当前经理任期内费用后表现、可投资同类基准、风险暴露、下行表现、风格和换手；市场上涨不全归经理 |
| 债券与流动性风险 | 实际久期、信用/利差、次级债与ABS、杠杆、集中度、持有人及申赎压力；低历史波动不等于无尾部风险 |
| 公司与经理事实 | 治理/风控、相关处罚及整改、任职/离任、共同管理和工作负荷、投研团队及运作变化，均带来源和可得时间 |
| 市场与账户暴露 | 已持仓和未持有机会的估值、利率、盈利或信用变化、汇率及重叠；新闻不能直接变成涨幅或加分 |

数值变量由训练、消融和滚动验证决定能否进入模型，不给公司名气、股东背景或明星经理固定百分比。定性问题若触发限制，引用具体事实和已声明规则，不悄悄变成未训练加分。旧任业绩不能全部归新任；共同经理不强行拆出个人功劳。

指标窗口、单位、基准、费用及缺失标记必须一致。收益、排名、夏普、Alpha等重叠信息须处理，不能重复奖励。公司/经理变量效果不稳定时不用作收益预测，仍保留事实尽调。

## 预测与评分定义

期限h单独建模，默认研究情景为30/60/90自然日，账户另有约定时沿用。成本窗口与经理评价历史窗口是不同概念，不把三个月历史自动当作充分管理能力样本。不同期限不靠累计收益大小直接互相排名。

最终比较从可执行申购到赎回到账的投资者净收益；预测层先估计净值总回报，账户申赎成本在组合执行层逐批扣除。主动基金另比较可投资同类基准的费用后超额收益。类别前景与基金实现质量分开。

使用 [组合数学与资金规范](allocation-method.md) 的Elastic Net总回报预测和联合情景CVaR约束求解，不再使用单基金U/S综合评分决定资金。均值预测不等于完整收益分布；当前可执行输入仍为5项净值特征，公司、经理和新闻尚不能因出现在文案中就自动取得数值权重。

同预算内在风险、交易资格和最低值得调整的改善要求满足后排序；跨预算给收益率、绝对尾部风险与追加资金的Pareto前沿。排名不是盈利概率。无风险口径或额度偏好时不编造唯一最优仓位或追加金额；CVaR不等于本金损失或最大回撤保证。

同底层份额的差异可确定为费用时，直接按实际条款和金额比较，无须训练模型猜测。模型不合格时可用帕累托比较排除明显被支配候选：至少一项更好且其他关键可比项不差。存在取舍时列理由和备选，不强行选唯一赢家，也不以临时主观评分恢复旧方法。

## 组合层与交易决策

基金评分和资金仓位独立。基于已确认风险口径、合格收益/风险输入及流动性约束，明确目标函数、相关性估计、费用、现仓和订单，再求解备选组合；记录参数来源和敏感性。没有合格求解和输入时只列候选、风险前沿或保留余额，不用经验比例冒充新模型输出。用户自行指定仓位可核算金额，明确不是优化结果。

组合比较必须同时纳入维持、内部调仓、追加买入、内部调仓加追加、减仓留现金。新增C要说明从A/B减多少、现金用多少或追加多少，不能孤立输出无资金支持的买单。追加方案按用户假设可获得资金，不追问来源；但只有实际确认到账才成为可用余额。保留零追加最佳方案和不卖原仓的追加备选，不默认哪类优先，也不把稀释B占比当作已经处理B本身的风险。

共同持仓、相同标的及相关性必须检查，不能将多只高分同类基金当作自动分散。模型研究金额与最终申购金额可能跨费率档，最终费用和交易金额按 [financial-analysis.md](financial-analysis.md) 重算。未知现金、在途与订单占用不得重复用于申购。

新增、维持、减持和更换按费用后利益及风险比较；资金需求、明确限制或已核实风险事件可单独处理，不必等待盈利预测。每日数据复核不强制交易，也不每日随新闻改模型系数。延长持有、更换和止损规则必须在策略验证前定义，不能事后只保留成功延期。

## 可审计输出

报告覆盖范围、平台/报价时点、准入与排除理由、同类组和期限、经理公司证据、成本、模型状态、预测/评分或未评分原因、选择取舍与组合依据。预测时单列区间/风险口径与数据完整性，避免把高分等同高确定性。

模型状态和参数、候选范围、所用资料、归一化、费用场景、评分及组合产物保存到活动计划的research/日期/run-id下。日常只读模型卡和所需分区，不把全市场原始行塞入上下文。不把生成分数、算术正确或静态审查称作已验证收益优势。
