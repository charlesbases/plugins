# SC08 内部设计：独立资格验证

文档版本：v1。状态：内部设计，待实现与验收。

[外部契约](README.md) · [公共契约](../../contracts.md) · [总体设计](../../architecture.md)

本子链编排访问审计、冻结政策回放、独立金融重建及科学检验。内部步骤产生私有评价证据，由汇总流程形成外部结论候选；步骤通过不自行授予下游许可。

## 步骤与私有结果

1. 鉴权流程核对被冻结政策、模型更新规则、当前动作和实验协议的准确引用，检查上游凭证及同方法族检验历史。对象未冻结、访问记录缺失或协议不就绪时停止相关评价，不能用新任务身份清除失败及已用检验次数。并独立读取原始目录/分页、DiscoveryAudit、来源处置、预测处置和实际计算记录；核查原同类名单闭合、全成员分区及全部风险保留，不只复核生产者清单。
2. 验证资料只向获准评价流程开放，保存实际访问轨迹，不向模型搜索或政策选择生产者提供未来结果。逐起点回放器重建当时信息、范围和合同，再调用冻结规则生成动作；滚动更新仅使用该起点之前已成熟且协议允许的资料，不借已见结果改规则。
3. 独立账本流程根据合法动作及来源合同重建资金、份额、费用和到账路径，不把生产者的汇总数字当成核对证明。私有核对结果记录差异、来源及影响，历史模拟、前瞻模拟与真实执行证据分别处理。
4. 范围核对器逐项验证 R 的来源与冻结规则、A 的真实计算证据、A = R，以及 R 外的客观排除或针对本任务的非重大影响证明。缺资料/模型、预算不足和人工标记不作豁免，未知与未比较保留；输出 comparison_scope_validation_ref。范围未核实限制完整同类用途，不借独立评价重新挑基金。
5. 配对比较器在相同账户与财富口径下评价政策和登记基准；误差及风险分析器按冻结指标、区间方法、有效样本与假设产生私有统计结果。计算可重现只证明计算过程，不能替代投资效果证据；工程样本数量不自动证明尾部充分。

## 扩展、并发与恢复

回放器、重建器或统计评价器可替换同能力方法，但必须保持评价对象、指标含义与判定规则。方法选择不得依据已经开放的验证成绩；需要修改时形成新试验，并遵循未接触证据或预登记重复检验处理。

独立核对及获准回放任务可并行，统一登记预算、失败和访问。区间计算使用协议约定的随机性与依赖结构；缓存绑定验证资料、冻结对象、起点、统计方法和检验历史。缓存命中不重置检验预算；同对象重算与新试验按协议区分，不能凭缓存重授许可。

## 输出与未决边界

汇总流程逐项执行必要门槛，将科学、风险与金融证据和拒绝原因组装为外部结论候选，提交独立阶段验收。证据不足与已证明失败分开；不重选赢家、不改金额、不授予未来盈利保证。有限集合评价及风险恢复单独注明范围，不作为完整研究达成的替代证据。当前信息截点及历史初始账户、批次和资金流规则保持待明确，不能用今天持仓冒充整链历史证明。

SC01只提供基金交易、确认份额、未完成交易和到账状态；资金计划与用户风险/期限/流动性约束由任务材料独立绑定，不从买卖差额反推余额、净资产或本金。缺少这些独立材料时限制依赖它们的结论，不反向阻止合法交易登记。
