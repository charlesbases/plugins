# SC03：事实评审与经济假说内部设计

文档版本：v1。状态：内部实现规划，待实现与验收。

[外部契约](README.md) · [公共规则](../../contracts.md) · [总体规则](../../architecture.md)

本页规划从原文到事实、经济观测和机制假说的内部流程。所有结论都须回到准确原文版本，分析器的解释不能代替来源证据。

## 步骤与私有结果

1. **登记评审任务。** 接收获准的 EvidenceCorpus、评审协议和分析者身份，展开全部待处理材料与研究问题，冻结抽取、核对和机制分析组件的版本及参数。
2. **抽取声明。** 从原文生成声明草稿和引文定位，保留主体、事件时间、已知时间及来源版本。定位无法复核的声明进入拒绝清单，不进入已接受事实。
3. **核对证据。** 将声明与支持、冲突及独立来源关系关联，按冻结规则产生事实草稿。转载或同源重复不提升核实等级，证据冲突保留 disputed。
4. **归并事件。** 按主体、时间和事件关系归并事实，保留原始声明映射，避免一件事件被重复计入。身份不能确定时保存未决关系，不强行合并。
5. **分析经济机制。** 从已核事实提出需求、供给、成本、政策或现金流渠道，生成机制草稿、替代解释及证伪条件。经济观测另存原值、单位、期间、币种和版本，不能混入预测值。
6. **汇总评审。** 为每个研究问题记录处理状态及理由，整理反证和 Gap；将事实、事件、假说、经济观测分别组装到 ResearchAssessment，再形成 CandidateOutput。

声明草稿、证据关系草稿、事件簇及机制草稿均为私有结果。支持关系不能循环，后续预测或组合结果不得回填为原始事实。

## 分析器扩展与并发

抽取、事实核对和机制解释分别登记分析能力。同能力 Analyzer 共享输入输出约定及方法版本；不同能力不能合并成一个通用分数。替换分析器须登记身份、参数和适用范围，不能静默改变核实规则。

不同文档或研究问题可并发处理，事件去重和证据关系由统一汇总步骤协调。单个分析器失败保留对应未处理项和 Gap；其他已核内容可继续组装。分析器分歧保留支持和反证，不以多数票自动确认事实，也不把缺少解释写成没有行业影响。

## 输出与边界

方法证据不足的机制保持探索属性，不能输出未经验证的收益概率。使用 LLM 时保存身份、版本、解释时点及可核训练时间信息；无法排除历史知识污染时保留证据用途限制。

生产者只组装 CandidateOutput。独立验证者核对引文、来源独立性、事实与假说分离及未决问题，签发 ValidationReceipt，调度者形成 SealedOutput。新增分析器不改变外部字段含义。
