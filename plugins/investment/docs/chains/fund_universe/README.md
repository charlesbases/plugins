## 外部业务定义

**问题。** 主动搜索同类完整列表，取得目录、身份与暴露证据，先确定原始比较分母，再逐成员判定研究准入，同时保留现有风险。不能先给定少数基金，再将这份集合称为完整同类范围。

**输入。** SC01 TransactionContext、SC03 ResearchAssessment、universe_discovery_spec_ref、eligibility_rule_ref、exposure_mapping_rule_ref、scope_time_request_ref。所需当前与历史时点由任务的 MethodPolicy 指定。

universe_discovery_spec_ref 登记渠道、币种、产品域、目录和列表来源、同类判定规则、搜索与分页规则、完整性判据及工程预算。这些规则由研究流程形成并审计，不要求用户填写。渠道和有源依据的产品适用范围可以限定研究任务；手选基金代码、基金白名单、top N、下载成功集合和模型排名不能限定原同类分母。同类范围须覆盖声明渠道和产品域内符合规则的各发行人；不能用单个发行人的列表代替跨发行人的同类列表。

catalog_vintage_ref 与 identity_evidence_refs 是可选复用资料，不是调用者必须预先取得的事实。未提供时，SC04 自行搜索和取材；提供时仍须核对准确字节、来源、时点和范围，不能用局部资料代替完整列表搜索。

**输出 InstrumentUniverse。**

| 字段 | 类型与语义 |
|---|---|
| universe_id、universe_at、universe_rule_ref | 冻结范围的身份、时点与构建规则 |
| members_ref | 原始发现名单 U；保留可能成员，是否完整由发现审计独立判定 |
| catalog_vintage_ref | OptionalValue<ArtifactRef>；取得或经核验复用的准确目录版本，未知时附原因 |
| discovery_audit_ref | DiscoveryAudit 的 ArtifactRef；原目录和分页、全部尝试、成员来源关系、可能成员、未处理范围及闭合证据 |
| universe_history_ref | OptionalValue<DatasetRef>；请求的各历史时点名单、准入分区及准确身份/暴露证据版本 |
| candidate_members_ref、excluded_members_ref、unknown_members_ref | 对 U 逐项形成的候选 C、证据排除 E、未知 K 三类处置 |
| peer_groups_ref | 同类组、判定规则、原始成员列表、可比依据及完整性结论 |
| exposure_links_ref | 基金份额类别、假说、暴露种类/权重或范围、披露及可得时间、原文来源 |
| mandatory_assets_ref | 基金登记持仓和未完成交易来自TransactionContext；现金比较对象及金额如需使用则绑定独立FundingPlan，未提供保持未知 |
| coverage_ref | 搜索来源域、已核范围、范围未知及限制 |

members_ref 不能由 NAV 下载成功、费用资料齐全或模型可运行来定义。每个成员保留原列表身份、同类组关系和来源引用。身份尚未确认的条目保留稳定 member_id 和原条目定位，基金代码以 OptionalValue 表达，不能捏造代码；尚不能确证同类归属的可能成员进入 K。尚未取得的分页、列表区间或来源范围进入发现审计，不捏造成员。

每项成员处置至少保留稳定身份、状态、适用规则、来源引用与原因。排除必须有源依据；没有资料、采集失败或预算耗尽不是客观排除理由。C 仅表示范围规则下的研究候选，不表示已经可买、具备合格预测或适合本次账户。

原目录条目D与调查成员U分别保留，身份合并不删除原定位。同类组分别记录C_g/E_g/K_g：原文已证非同类用proven_not_peer和分类引文表达。成员在任一组合格即属于全局C；没有合格关系但仍有可能合格的组则为K；仅所有所涉组都有据排除或不准入才为全局E。一个组的排除不能覆盖另一组的合格关系，组内未知也不重复写成互斥的全局处置。

DiscoveryAudit 的公共字段见 [公共契约](../../contracts.md)。闭合须能从原始列表、分页关系、来源声明及同类规则复核；列表数量、下载数量和自哈希不能单独证明完整性。来源列表是否覆盖所声明渠道和产品域也是必要检查，不能以局部来源已翻页结束证明整个同类范围闭合。

**方法。** 主动目录和同类列表发现、身份与合同准入、集合分区及来源支持的资产暴露映射。同类规则基于可核法律基金与份额身份、基准主体及目标、资产类别、币种和有关策略口径，按声明的比较任务确定。基金名称或关键词只能形成取材线索，不能认证同类身份；身份、基准或口径未知的可能成员不能直接丢弃。

**内部链路。** 范围和同类规则登记 → 主动搜索目录及原同类列表 → 身份/基准/披露取材 → 暴露和同类归属核验 → 原始分母冻结 → 逐成员准入处置 → 当前及历史范围汇总。

**验收。** 先核对原始同类列表及闭合证据，再核对 U = C ∪ E ∪ K，三组两两不相交。每个原始成员恰好有一种处置，未知不可删除。全部待研究假说和暴露，以及需要比较的持仓产品，都有对应搜索任务、同类范围或有证据的不适用说明。持仓和在途风险不因缺新闻关联而移除。

独立验证者从原始目录、列表、身份材料和分页关系复核成员及闭合结论，不只核对生产者生成的集合。完整性未知、分页未完成或可能成员身份未决时，限制完整同类比较用途；可以保留已核材料和观察结论，不能称完整同类择优已完成。列表完整不意味着所有成员可买或具备模型资格，也不在此阶段授予最佳基金资格。

**历史验证。** 整链回放必须逐时点重建当时目录、身份、暴露与准入范围，保留后来消失的对象。以今天候选回放过去，只能给出条件候选集研究结果。

**来源与数值口径。** 主动发现可从[天天基金公开目录](https://fund.eastmoney.com/allfund.html)进入，沿本轮实际档案及公告链接核实具体产品；目录抓取成功不证明渠道、跨发行人及产品域闭合。法律基金、份额类别和收费代码分别核实，名称仅作线索。暴露比例采用原披露的精确十进制与分母；合同约束、基准成分和实际持仓分别表达，未知不估算。来源依据、模型假设及局限见精确规范。

universe_history 每个已支持时点至少包含 origin_at、universe_version_id、member_id、entity_id、membership_status、identity_version_ref、exposure_version_refs、eligibility_rule_ref、availability_bound_at；未确认 entity_id 使用 OptionalValue。请求时点缺历史证据进入 Gap，不能用今日成员补齐。当前范围可用但历史范围未知时，只授予对应当前研究用途。

**失败路径。** 来源失败、列表未闭合和身份冲突保留实际尝试、可能成员及未知范围，不删除成员以满足验收。无法取得必要目录或列表证据时，不补造目录，也不把空集合写成确认没有同类；由控制记录和 Gap 说明失败边界。可用资料的观察用途与完整比较资格分别判定。
