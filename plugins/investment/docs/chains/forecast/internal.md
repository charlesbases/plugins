# SC06 内部设计：预测与联合情景

文档版本：v1。状态：内部设计，待实现与验收。

[外部契约](README.md) · [公共契约](../../contracts.md) · [总体设计](../../architecture.md)

本子链编排折内学习、候选比较、预测生成和联合分布构建。预测器与情景生成器分开承担责任，私有模型结果只供获准研究，不授予金额或风险资格。

## 步骤与私有结果

1. 输入守门流程解析封存引用，核对目标、期限、基金范围及训练和选择权限。每个任务获得受限数据视图；独立验证的未来结果不可访问。当前信息截点的具体规则仍待明确，不按数据最新日期自行推定。先绑定原始名单及发现/取材审计，再建立全体成员的预测处置；真实训练只读获准视图，不以可运行基金替代原名单。
2. 折内流水线依时间顺序构建训练任务，核对标签覆盖和成熟时间，再拟合标准化、插补及特征处理。私有折产物保存处理器、模型、参数依据和输入版本；任何拟合结果都不能从后续折倒传前折。
3. 候选预测器可采用已登记的不同算法，但必须输出相同目标、时期、单位及条件信息下的估计。各算法的任意评分不得直接合并为收益概率。候选比较只使用获准选择资料，保存全部尝试、拒绝依据和选参记录。
4. 选定流程产生历史样本外预测及当前预测，冻结训练与更新规则。联合情景流程另行核对依赖结构、稳定性、尾部样本及参数依据，再生成共享时间轴和概率权重的资产路径。条件均值不能代替完整分布，不能拼接不同基金各自有利路径。

5. 汇合每个原成员的实际预测、ready/unknown/有据不适用处置及依据，组装 member_forecast_dispositions_ref。缺资料、失败或预算耗尽保留未知，不把未运行模型写成模型已否定；实际持仓和在途风险另行保留。只有真实产生的模型/情景对象进入对应产物，后续依原名单核对实际比较补集。

## 扩展、并发与恢复

情景生成器或诊断器可以替换同能力方法，但需保持目标、依赖与概率语义，记录新方法版本并按协议重新评价。共同分布供全部比较方案使用，概率总和为 1，规范化遵循已登记规则；证据不足保留具体缺口，不制造默认风险或上涨概率。

候选及训练折可以在协议授权的搜索预算内并行，统一记录计算、失败、随机性与已用比较次数。缓存绑定获准数据内容、训练截点、折划分、处理和模型版本、目标及随机性规则；跨分区复用不得绕过成熟或访问检查。

## 输出与未决边界

组装器将实际拟合模型、更新规则、预测、情景及审计转为外部候选包，再交独立阶段验证。未拟合、参数依据缺失、方法假设不成立或必要输入未就绪时，返回对应失败或证据不足结果。历史账户规则保持未决，不借预测流程补造账户或声称已验证当前投资效果。
